# DA Tech Solutions – Website Template

A responsive website template for an IT services business, featuring service listings, product showcases, and contact information.

## About

DA Tech Solutions is a modern, responsive website template designed for a technology services business. It provides a clean and professional online presence, with dedicated sections for services, products, company information, and contact details.

Built with HTML, SCSS, and JavaScript, the project uses MDBootstrap 5 for its responsive layout and UI components, with Vite for development and production builds.

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Dedicated sections for services, products, about, and contact information
- Modern UI with MDBootstrap 5
- Custom SCSS styling
- Font Awesome icons

## Technologies

- HTML
- SCSS
- JavaScript
- MDBootstrap 5
- Font Awesome
- Vite
